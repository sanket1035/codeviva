**Q1. What does the function `average` do?**

`average` takes 1 input(s) (marks). Return the mean of a list of marks. It uses 1 loop(s).

**Q2. What does the function `grade` do?**

`grade` takes 1 input(s) (avg). Convert an average to a letter grade. It makes 3 decision(s) with if/else.

**Q3. What does the function `topper` do?**

`topper` takes 1 input(s) (students). Return the name of the student with the best average. It uses 1 loop(s). It makes 1 decision(s) with if/else. It calls `average`.

**Q4. Which functions does `topper` call and why?**

It calls average.

**Q5. What does the function `report` do?**

`report` takes 1 input(s) (students). It uses 1 loop(s). It calls `average`, `topper`, `grade`.

**Q6. Which functions does `report` call and why?**

It calls average, topper, grade.
